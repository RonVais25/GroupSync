# GroupSync

Interactive prototype for an HCI course project — a mobile app concept for group coordination, presented as an iOS-framed mockup with switchable roles (Leader / Student) and an AI Scout assistant.

**Live demo →** <https://ronvais25.github.io/GroupSync/>

> Work in progress — not yet final.

## About

The prototype walks through several screens (lockscreen, dashboard, case view, tracking, task detail, calendar, confirmation) and includes a side **Tweaks** panel for toggling dark mode, Daniel's auto-replies, anatomy callouts, and a couple of test actions. UI is in Hebrew (RTL).
