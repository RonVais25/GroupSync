# GroupSync

Interactive prototype for an HCI course project — a mobile app concept for group coordination, presented as an iOS-framed mockup with switchable roles (Leader / Student) and an AI Scout assistant.

**Live demo →** <https://ronvais25.github.io/GroupSync/>

> Work in progress — not yet final.

## About

The prototype opens on the leader's home dashboard and walks through several screens (dashboard, case view, tracking, task detail, calendar, confirmation, plus the lockscreen push entry) with a persistent bottom tab bar that behaves like a real app — present on the main areas, hidden on pushed detail screens. A side **Demo** panel consolidates role switching (Noa / Yoav), quick screen-flow navigation, and dev toggles (dark mode, Daniel's auto-replies, test actions). The two required flows are fully navigable on their own, without the demo panel. UI is in Hebrew (RTL).
